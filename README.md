### Описание
Этот проект представляет собой учебную программу на языке C++. Программа создает пароли - пользователь указывает длину пароля, количество паролей, и программа выводит результат в консоль.

!!! Внимание!!!
Данный проект преследует исключительно образовательную цель. Автор не обладает квалификацией специалиста по кибербезопасности. Программа не гарантирует криптографическую стойкость паролей. Пользователь применяет созданные пароли на собственный риск.

### Требования / Requirements
Стандарт C++17 или более новый
Стандартные библиотеки <random>, <vector> и <algorithm>.

### Инструкция по запуску / Launch Instructions
Откройте файл main.cpp, в консоли введите желаемую длину пароля, количество паролей по запросу программы. Выбирайте нужный и копируйте куда надо. Не забудьте его где-то сохранить.
